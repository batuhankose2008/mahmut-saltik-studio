# Mahmut Saltık Studio — Release

Bu commit, Render üzerinde deploy edilecek güncel sürümü işaretler.

## İçerik

- Public portfolyo ve galeri akışı
- Admin giriş paneli
- Görsel/video medya yükleme ve önizleme
- Supabase Storage upload akışı
- Eser düzenleme, yayınlama, gizleme ve silme
- Sıra numarası ve öne çıkarma kontrolü
- Profil ve Stüdyo Günlüğü yönetimi
- Yorum moderasyonu
- WhatsApp ve Instagram iletişim akışları
- Render Docker yapılandırması ve Supabase migration’ları

## Deploy

Render’da **Manual Deploy → Deploy latest commit** seçilmelidir. Deploy tamamlandıktan sonra `/api/health` endpointi kontrol edilmelidir.
